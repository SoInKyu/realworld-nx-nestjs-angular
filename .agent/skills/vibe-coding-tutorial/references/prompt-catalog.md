# Prompt Catalog - Vibe Coding Migration

실제 세션에서 사용된 프롬프트를 Phase별로 정리한 카탈로그입니다.

## Phase 1: 프로젝트 분석 및 문서화

### P1-1: 심층 인터뷰 시작

```
이 프로젝트를 바이브 코딩을 위한 프로젝트로 전환하려 해.
문서화 및 테스트 CI/CD까지 진행할꺼야. 이를 위한 심층인터뷰를 진행해줘.
```

### P1-2: CLAUDE.md 생성

```
/init
```

> `/init` 명령은 Claude Code가 코드베이스를 분석하여 CLAUDE.md를 자동 생성합니다.

### P1-3: OpenSpec 문서화

```
openspec을 사용해서 이 프로젝트의 문서화 해줘.
```

### P1-4: 전환 계획 문서 생성

```
@docs/vibe-coding-transition-plan.md를 만들어줘.
해당 문서를 통해 작업 배경, 개요, 인수조건이 들어가야 하고,
다른 작업과 의존 관계가 있을 경우 의존 관계도 기술되어 있어야 해
```

### P1-5: Epic 이슈 등록

```
@docs/vibe-coding-transition-plan.md를 gh issue로 등록해줘.
이슈에는 작업 배경, 개요, 인수조건이 들어가야 하고,
다른 작업과 의존 관계가 있을 경우 의존 관계도 기술해줘.
```

## Phase 2: 스킬 생성

### P2-1: 프로젝트 스킬 생성

```
만들어진 문서들을 이용해서 이 프로젝트에서 필요한 클로드 스킬을
공식 문서에 따라서 만들어줘.
궁금한게 있으면 askuserquestiontool을 사용해서 심층 인터뷰를 진행해
```

### P2-2: 스킬 최적화

```
스킬에서 참고할 문서와 사이즈가 너무 클 경우 공식문서화 권고대로 분할해서 사용해
그리고, 핵심 지시사항만 SKILL.md에 넣고 상세 내용은 기존에 작성된 문서들을 링크해서 사용해.
마지막으로 만들어진 스킬들에 대해서 설명하는 문서 만들어줘
```
